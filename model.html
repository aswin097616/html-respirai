The RespirAI Classification Model

Our core technology is a sophisticated deep learning framework designed specifically for audio biometrics. The model processes the raw audio data through three main stages to deliver an accurate classification.

1. Preprocessing and Feature Extraction

Spectrogram Conversion: Each segment is converted into a 'Mel-Spectrogram'. This visual representation of the sound's frequency over time is used as the primary input image for the neural network.

2. Machine Learning Model

Convolutional Neural Networks (CNN): The CNN layer analyzes the 2D spectrogram image, acting as a powerful feature extractor to identify localized patterns like the distinct shape of a wheeze or a crackle.
